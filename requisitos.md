# Requisitos do Sistema

## Requisitos Funcionais

| Código | Descrição |
|---|---|
| RF01 | Cadastrar clientes |
| RF02 | Cadastrar pets |
| RF03 | Consultar clientes e pets |
| RF04 | Cadastrar serviços |
| RF05 | Agendar serviços |
| RF06 | Registrar atendimentos |
| RF07 | Cadastrar produtos |
| RF08 | Registrar vendas |
| RF09 | Consultar histórico de atendimentos |
| RF10 | Gerar consultas e relatórios básicos |

## Requisitos Não Funcionais

| Código | Descrição |
|---|---|
| RNF01 | O sistema deverá possuir autenticação para usuários administrativos. |
| RNF02 | A interface deverá ser responsiva. |
| RNF03 | Os dados deverão possuir rotina de backup. |
| RNF04 | O sistema deverá apresentar mensagens claras de erro e confirmação. |
| RNF05 | O sistema deverá proteger os dados cadastrados contra acesso não autorizado. |
