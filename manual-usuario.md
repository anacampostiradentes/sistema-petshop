# Manual do Usuário

## 1. Acessar o sistema
Entre no sistema com um usuário autorizado.

## 2. Cadastrar cliente
Acesse **Clientes → Novo cliente**, preencha os campos e salve.

## 3. Cadastrar pet
Acesse **Pets → Novo pet**, selecione o cliente responsável e informe os dados do animal.

## 4. Agendar serviço
Acesse **Agendamentos → Novo agendamento**, escolha cliente, pet, serviço, data e horário.

## 5. Registrar atendimento
Após o serviço, registre o atendimento e as observações necessárias.

## 6. Registrar venda
Selecione os produtos e quantidades. O sistema deve calcular o total e atualizar o estoque.

## 7. Consultar informações
Use as opções de consulta para localizar clientes, pets, serviços, vendas e históricos.
