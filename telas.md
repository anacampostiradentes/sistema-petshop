# Telas

## Tela de cadastro de cliente
A tela deve permitir informar:
- Nome
- Telefone
- E-mail
- Endereço

## Tela de cadastro de pet
Campos sugeridos:
- Nome do pet
- Espécie
- Raça
- Idade
- Cliente responsável

## Tela de agendamento
Campos:
- Cliente
- Pet
- Serviço
- Data
- Horário
- Status
