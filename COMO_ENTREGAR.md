# Como entregar no GitHub

## 1. Criar o repositório
No GitHub, clique em **New repository**.
Nome sugerido: `sistema-petshop`.
Marque **Add a README file** se criar o README pelo GitHub.

## 2. Enviar os arquivos
Você pode usar **Add file → Upload files** e enviar o conteúdo desta pasta.

## 3. Primeiro commit
Mensagem sugerida:
`docs: criação da documentação inicial`

## 4. Segundo commit
Depois de conferir requisitos, regras, casos de uso e imagens:
`docs: documentação de requisitos e casos de uso`

## 5. Ativar GitHub Pages
No repositório:
**Settings → Pages → Source/Deploy from a branch → branch main → pasta /docs → Save**.

O arquivo `docs/index.html` será a página inicial da documentação.

## 6. Endereço
O endereço normalmente ficará parecido com:
`https://SEU-USUARIO.github.io/sistema-petshop/`

Substitua `SEU-USUARIO` pelo seu nome de usuário do GitHub.
