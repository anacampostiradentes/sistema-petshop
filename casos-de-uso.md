# Casos de Uso

## Atores
- **Administrador/Funcionário:** gerencia cadastros, serviços, produtos, agendamentos e vendas.
- **Cliente:** fornece seus dados, dados do pet e solicita serviços.

## Casos de uso principais
- Cadastrar cliente
- Cadastrar pet
- Consultar cliente/pet
- Cadastrar serviço
- Agendar serviço
- Registrar atendimento
- Cadastrar produto
- Registrar venda
- Consultar histórico
- Gerar relatório

## Fluxo principal de agendamento
1. Funcionário localiza ou cadastra o cliente.
2. Seleciona o pet.
3. Escolhe o serviço.
4. Define data e horário.
5. O sistema verifica a disponibilidade.
6. O agendamento é registrado.

O diagrama de casos de uso está em `assets/diagrama-casos-de-uso.svg`.
